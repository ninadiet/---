## 🚫 NGパターン・失敗事例集（2026年5月追加分）

> このセクションはルーナ（lw_agent）とマルフォイ（mf_agent）が参照します。
> 避けるべき表現・構成のリストです。

### ❌ NGパターン1：「〜してみた」で終わる締め

**問題のある例：**
```
Geminiを使って資料を作ってみた。
なかなか便利だった。
また使ってみたい。
```
**なぜNG：** 読者に行動を促す要素がない。保存・シェアされない。
**改善後：**
```
Geminiで資料作成を試したら、いつもの半分の時間で終わった。
まず「専門家ペルソナ設定」を試してみて。それだけで別次元になる。
```

---

### ❌ NGパターン2：抽象的すぎる開幕

**問題のある例：**
```
AIって本当にすごいですよね。
これからの時代、AIは欠かせないと思います。
みなさんも活用してみてはいかがでしょうか。
```
**なぜNG：** 誰でも言えること。個人の「声」がゼロ。冒頭で離脱される。
**改善後：** 具体的な数字・体験・問いかけで始める

---

### ❌ NGパターン3：長すぎるリスト

**問題のある例：**
```
AIで効率化できる作業10選
① メール返信
② 資料作成
③ データ分析
④ スケジュール管理
⑤ 翻訳
⑥ 画像生成
⑦ 動画編集
⑧ コード生成
⑨ リサーチ
⑩ 企画書作成
```
**なぜNG：** 情報量が多すぎて記憶に残らない。「全部知ってる」と思われる。
**改善後：** 3〜5個に絞り、各項目に「なぜこれが特別か」を1行添える

---

### ❌ NGパターン4：煽り・断言型

**問題のある例：**
```
AIを使わない人は時代遅れです。
この方法を知らないと損します。
今すぐやらないと後悔しますよ。
```
**なぜNG：** 読者を不快にさせる。フォロー解除のリスク。
**改善後：** 「私はこうだった」という体験ベースの語り口に変換

---

### ❌ NGパターン5：「〜ですね」「〜ましょう」系の語尾多用

**問題のある例：**
```
AIは便利ですね。
ぜひ使ってみましょう。
効率化できますよ。
```
**なぜNG：** 一方的な語り口。対話感がない。距離感が生まれる。
**改善後：** オーナーの自然な語尾（owner_voice設定を参照）を使う

4. Meta Developers から新しいトークンを取得
5. GitHubリポジトリ → Settings → Secrets → THREADS_ACCESS_TOKEN を更新
