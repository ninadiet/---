# 裏取りの台帳（自動で溜まります）

このフォルダには、**その日の投稿を書く前に調べた内容と出典**が
`YYYY-MM-DD.md` の形で1日1本ずつ自動で残ります。あなたが書き込む必要はありません。

## 何のためにあるか

投稿に数字や事実を書くとき、**どこで見た話なのかを後から辿れる**ようにするためです。
「この数字どこから持ってきたっけ？」が無くなります。

## 中に入っているもの

| 項目 | 内容 |
|---|---|
| 区分 | 一次情報（公式・発表元）か、二次情報（まとめ記事等）か |
| ドメイン | どのサイトか |
| 取得日 | いつ調べたか |
| URL | 元のページ |

## よくある行

- **「本日は裏取りなし」** … その日は検索が使えなかった、または引用が1件も取れなかった、
  という記録です。**エラーではありません。** この日の投稿は、
  あなたの素材帳（`operation/my_material.md`）と手持ちのナレッジだけで書かれます。

## 注意

- 中のファイルを消しても投稿は動きます（記録が消えるだけです）
- 溜まりすぎたら古い月のファイルは消して構いません
